First steps

In this chapter, you'll create a Go project, add Dygo and run your first endpoint. You only need one file to get a server running.

Hint Dygo needs Go [MINIMUM VERSION] or later. Run go version to check yours.

Install

Create a new module with go mod init, then add Dygo with go get.

Terminal BASH
{{tok.text}}

Create your first app

The following example uses dygo.New() to create an app. The app.GET() method registers a handler for the /hello path, and c.JSON() writes the response.

main.go GO
{{tok.text}}

Run the server

Start the app, then open localhost:8080/hello in your browser.
