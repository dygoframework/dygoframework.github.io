First steps

In this chapter, you'll create a Dygo project, add a feature and run it with live reload.

Hint Dygo needs Go 1.27 or later. Run go version to check yours.

Install

Install the dygo command, then create a project.

Terminal BASH
{{tok.text}}

Add a feature

dygo g resource products writes a service, a controller and a module. The controller binds typed input and returns JSON:

products.go GO
{{tok.text}}

Run the server

Start the app with live reload, then open localhost:9900/docs for the OpenAPI UI.

Terminal BASH
{{tok.text}}
