Modules

Constructor injection

Route comments

Put the route beside the method. dygo gen writes the Go for you.

//dygo:controller /products type Controller struct{ svc *Service } //dygo:get /{id} func (c *Controller) Get(...)

Security rules

Describe who can call what in one ordered list. Everything else needs login.

Security

Checked against the OWASP Top 10 on every change, and the safe choice is the one you get without asking.

  • Deny by default with dygo new -security
  • Secure headers and CORS in new projects
  • Strict JSON and body size limits
  • OWASP Top 10 checks in CI

Performance

Typed JSON handlers cost the same as hand-written net/http.

  • Typed JSON handlers within 1% of net/http
  • About 2x faster than Gin and Huma on JSON
  • The fewest allocations on JSON requests
  • Slower than net/http and Gin on static routes
