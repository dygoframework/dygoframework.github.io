Dygo

The Dygo Framework for Go

Secure by default.
Fast by design.

Dygo is a Go backend framework built around two priorities: keeping your services safe and keeping them fast.

Get started GitHub
go get github.com/[YOUR-ORG]/dygo

Security

Common protections are on from the start, so a new service isn't exposed by a missed setting.

  • Secure headers by default
  • Built-in rate limiting
  • Strict request validation
  • Safe error responses

Performance

A small, efficient core keeps latency low and leaves more of your server for your own code.

  • Fast route matching
  • Low-allocation request handling
  • Graceful handling under load
  • Built-in profiling
