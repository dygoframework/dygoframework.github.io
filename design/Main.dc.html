A modular, secure-by-default web framework for Go. Modules, dependency injection and typed handlers, on plain net/http, with a core that uses only the standard library.

How we measure

Familiar by design.

Structure a Go backend with patterns your team already knows, in plain, readable Go.

Modules

Group each feature's services and controllers in one place.

var Module = &dygo.Module{ Name: "products", Providers: []dygo.Provider{dygo.Provide(NewService)}, Controllers: []dygo.Provider{dygo.Provide(NewController)}, }

Constructor injection

Ask for what you need. The whole graph is checked when the app starts.

func NewController(svc *Service) *Controller { return &Controller{svc: svc} }

Route comments

Put the route beside the method. dygo gen writes the Go for you.

//dygo:controller /products type Controller struct{ svc *Service } //dygo:get /{id} func (c *Controller) Get(ctx context.Context, in GetIn) (Product, error)

Security rules

Describe who can call what in one ordered list. Everything else needs login.

Path("/health/**").PermitAll(), Path("/admin/**").HasRole("admin"), AnyRequest().Authenticated(),

Security

Dygo is checked against the OWASP Top 10 on every change, and the safe choice is the one you get without asking.

  • Deny by default with dygo new -security
  • Secure headers and CORS in new projects
  • Strict JSON and body size limits
  • OWASP Top 10 checks in CI
What stays with your app

Performance

Typed JSON handlers cost the same as hand-written net/http. A fixed cost of about 0.5 µs per request shows on routes with almost no work.

  • Typed JSON handlers within 1% of net/http
  • About 2x faster than Gin and Huma on JSON
  • The fewest allocations on JSON requests
  • Slower than net/http and Gin on static routes
